Weather App

This project is a responsive weather application that fetches real-time weather data for any city in the world. It uses an external weather API to display live information such as temperature, humidity, wind speed, and weather conditions. The clean UI allows users to simply enter a city name and instantly view accurate global weather.

Car Simulation Game (Unity)

This is a 3D car-simulation game built in Unity where the player navigates a car through a virtual city and collects coins before the timer runs out. It includes a smooth driving system, countdown timer, collision detection, coin collection mechanics, and a fully designed city environment. This project helped me learn Unity physics, C# scripting, UI timers, and game environment design.
